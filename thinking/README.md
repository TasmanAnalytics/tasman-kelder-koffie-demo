# Thinking folder

Working notes for the build. Never copied into an agent workspace.

- `context.md`: what the build is, constraints, gates that need Thomas.
- `decisions.md`: running list of design decisions with reasons (mirrored into `BUILD_LOG.md` when they deviate from the brief).
- `generator_design.md`: how the world simulation, rendering and incidents fit together.
- `dbt_design.md`: model plan for the three states.
- `progress.md`: where the build is, what is next.
